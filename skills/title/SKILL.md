---
name: title
description: Renames the current chat session so its title says what was actually done, not just what the first message asked. Use when the user asks to rename, retitle, or fix the title of this chat or session, or types /title. Don't use it unasked at the end of other work.
---
Rename the session so the user can find it later by what was done.

- If the user gave an exact title, use it as written.
- Name the outcome, not the opening request: "Fix circular import slowing Vite build", not "Why is my build slow". If the work didn't finish, don't say it did: "Debugging flaky login test".
- Keep it under about 60 characters, because sidebars cut long titles off.
- If you have no tool that renames the session, don't say you renamed it. Give the title in a form that's easy to copy and say where to set it.
