# Sources

job-search had no upstream skill: it follows the preferences Justin set in an interview on 2026-11-12. These job-search, application, and resume-tailoring skills were reviewed against it, led by career-ops (by far the most used) and srikar0805's career-agent. The rules most of them share (never invent experience, never submit for the user, fewer and better applications, keep a record of every posting seen) were already in the plan; the rows below credit what each added.

Pins are the commits reviewed on 2026-11-12. **Track** marks the sources worth checking for updates; the rest are credited only. No text was copied, so there is no NOTICE.md.
